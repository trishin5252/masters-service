# Сервис поиска мастеров

## Назначение
Консольное приложение для поиска мастеров (сантехников, электриков, репетиторов и т.д.), просмотра их услуг и оформления заказов.

## Целевая аудитория
- Частные лица, которым нужны услуги мастеров
- Мастера, желающие предложить свои услуги

## Предметная область
Сервис по поиску и заказу услуг частных мастеров различных специальностей.

## Основные сущности
- **Клиент** — заказчик услуги
- **Мастер** — исполнитель услуги (ФИО, специализация, рейтинг, опыт)
- **Услуга** — вид работы, предлагаемый мастером (название, цена, длительность)
- **Заказ** — оформленная заявка клиента на услугу мастера

## Основные функции
- Просмотр списка мастеров и их услуг
- Поиск мастера по специализации
- Оформление заказа на услугу
- Просмотр истории заказов клиента
- Расчет стоимости заказа

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django
- подключение базы данных
- реализация регистрации и авторизации пользователей
- разработка REST API
- контейнеризация приложения
- настройка CI/CD
