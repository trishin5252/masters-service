# Сервис поиска мастеров

## Назначение
Веб-приложение для поиска и записи к мастерам различных специальностей. Позволяет клиентам находить подходящих специалистов, просматривать их профили, отзывы и записываться на услуги.

## Целевая аудитория
- Частные клиенты, нуждающиеся в бытовых и профессиональных услугах
- Мастера и специалисты, ищущие клиентов
- Владельцы небольших сервисных компаний

## Предметная область
Рынок услуг и сервисного обслуживания. Платформа соединяет заказчиков с исполнителями, обеспечивает запись, оценку качества и ведение истории обращений.

## Основные сущности
- Клиент (пользователь, заказывающий услугу)
- Мастер (специалист, оказывающий услугу)
- Услуга (вид работы с ценой и описанием)
- Заказ (запись клиента к мастеру на определённое время)

## Основные функции
- Поиск мастеров по категории услуги
- Просмотр профиля мастера и отзывов
- Запись на услугу с выбором даты и времени
- Оценка качества выполненной работы
- История заказов клиента

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django
- подключение базы данных (PostgreSQL)
- реализация системы пользователей и аутентификации
- разработка REST API
- контейнеризация приложения в Docker
- настройка CI/CD
