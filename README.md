# Сервис управления задачами (Task Manager)

## Назначение
Веб-приложение для управления личными и командными задачами. Позволяет создавать, отслеживать и организовывать задачи с возможностью назначения исполнителей и установки сроков.

## Целевая аудитория
- Фрилансеры и удаленные сотрудники
- Небольшие команды (до 10 человек)
- Студенты для управления учебными проектами

## Предметная область
Управление задачами и проектами. Система позволяет организовывать работу, назначать ответственных, отслеживать прогресс и сроки выполнения.

## Основные сущности
- Пользователь (создатель задач, исполнитель)
- Проект (группа задач)
- Задача (основная единица работы)
- Комментарий (обсуждение задачи)

## Основные функции
- Создание и редактирование задач
- Назначение исполнителей
- Установка приоритетов и сроков
- Отслеживание статуса выполнения
- Комментарии и обсуждения

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django
- подключение базы данных (PostgreSQL)
- реализация системы пользователей и аутентификации
- разработка REST API
- контейнеризация приложения в Docker
- настройка CI/CD
