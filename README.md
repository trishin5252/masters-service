# Сервис поиска мастеров

Консольное приложение для поиска мастеров различных специальностей и управления заказами на услуги.

## Назначение

Приложение позволяет находить мастеров по специальности, просматривать их профили с рейтингом и опытом работы, а также создавать и управлять заказами на услуги с указанием даты выполнения.

## Целевая аудитория

- Частные клиенты, нуждающиеся в бытовых и профессиональных услугах
- Мастера и специалисты, ищущие заказы
- Владельцы небольших сервисных компаний

## Предметная область

Рынок услуг и сервисного обслуживания. Платформа соединяет заказчиков с исполнителями, обеспечивает поиск мастеров, проверку их доступности и ведение истории заказов.

## Основные сущности

**Мастер** — специалист, оказывающий услуги. Содержит информацию: уникальный идентификатор, ФИО, специальность, опыт работы в годах, рейтинг от 0 до 5, цена за час работы.

**Заказ** — бронирование мастера клиентом. Содержит: уникальный номер заказа, идентификатор мастера, имя клиента, название услуги, дата записи, статус заказа (создан или отменён).

**Пользователь** — клиент сервиса. Пользователи хранятся в `data/users.json` и связываются с заказом через поле `user_id`. Отдельная регистрация и авторизация в рамках этой практической работы не требуются.

**Услуга** — вид работы, который выполняет мастер. Содержит: идентификатор, название услуги, категория (сантехника, электрика и т.д.), примерное время выполнения в часах.

## Основные функции

### Работа с мастерами
- Поиск мастера по уникальному идентификатору
- Поиск мастеров по специальности (поиск по подстроке)
- Фильтрация мастеров по минимальному рейтингу
- Сортировка мастеров по рейтингу (от высокого к низкому)
- Получение текстового описания мастера

### Работа с заказами
- Создание нового заказа
- Поиск всех заказов конкретного мастера
- Отмена заказа по номеру
- Получение текстового статуса заказа
- Проверка доступности мастера на дату

### Работа с пользователями
- Хранение пользователей в JSON-файле
- Поиск пользователя по идентификатору
- Привязка пользователя к заказу

### Работа с данными
- Загрузка данных из JSON-файлов
- Сохранение данных в JSON-файлы
- Обработка ошибок при работе с файлами

### Вспомогательные функции
- Ввод целых чисел с проверкой корректности
- Ввод даты в формате год-месяц-день с проверкой
- Отображение главного меню приложения

## Объектная модель ПР3

Основные сущности проекта представлены классами:

- `Master` в `masters.py` хранит данные мастера и формирует его строковое представление.
- `User` в `users.py` хранит клиента сервиса и умеет преобразовываться в JSON-данные.
- `Order` в `orders.py` хранит ссылки на объекты `Master` и `User`, дату и состояние заказа. Методы `cancel()` и свойство `is_cancelled` управляют состоянием заказа.

Коллекции приложения теперь содержат объекты. Модуль `storage.py` преобразует JSON в объекты при загрузке и объекты обратно в JSON при сохранении. Функции поиска, фильтрации, сортировки и статистики работают с коллекциями объектов.
